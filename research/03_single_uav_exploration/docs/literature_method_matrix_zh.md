## 3. 方法继承关系

```text
在线局部观测
  -> 三维占据地图
  -> Frontier 检测
  -> 单机 Frontier 访问与安全轨迹（FUEL 基线）
  -> 多机动态拓扑任务表示（借鉴 GVP-MREP）
  -> 三机任务分配、去重复和重分配（对比 RACER/GVP-MREP）
  -> 可选强化学习优化分配权重（不是底层飞行控制）
```

这条路线保持了明确的因果关系：先证明无人机能够在未知地图上自主完成
单机闭环，再研究多机带来的独有问题。否则强化学习训练失败时，无法判断
问题来自感知、地图、局部规划、控制还是协同策略。

## 4. 本文拟采用的研究问题

主问题不是“给定目标坐标后如何到达”，而是：

> 在先验地图不可用的复杂三维废墟中，三架无人机如何仅根据在线局部观测
> 产生的 Frontier 和动态拓扑信息，减少重复探索并缩短达到规定地图覆盖率
> 所需的时间，同时保持可通行性、避碰和受限通信条件下的任务连续性。

目标点不是预先写入的固定坐标。每个探索目标都是当前地图更新后才产生的
候选 Frontier 视点；某个 Frontier 被观测、阻塞或分配后，目标集合会变化。

## 5. 小论文的创新边界

建议保留两个主要贡献，避免范围失控：

1. 构建带可量化拓扑和几何难度、支持固定及未见随机种子的三维废墟基准；
2. 提出基于在线动态拓扑信息的三无人机 Frontier 分配与重分配方法，在
   FUEL 单机和无协同多机基线上验证探索时间、重复率、路径和通信开销。

强化学习只能作为附加优化：学习任务分配效用中的权重或策略，不能替代
底层碰撞检查、轨迹规划和飞行控制。
